## 📌 Overview
This project performs sentiment analysis on 50,000 IMDB movie reviews using classical NLP & ML techniques.

## 📂 Dataset
- 50,000 labeled reviews  
- Balanced dataset  
- Columns: `review`, `sentiment`

## 🧠 Project Workflow
1. EDA  
2. Text Preprocessing  
3. Feature Engineering  
4. Model Training  
5. Evaluation  

## 🧹 Text Preprocessing
- Contractions  
- Lowercasing  
- Remove HTML, URLs, Emojis, Punctuation  
- Tokenization  
- Stopword removal  
- Lemmatization  
- Label encoding  

## 🤖 Models Trained  
- Logistic Regression  
- Naive Bayes  
- Linear SVM  
- XGBoost  

## 📊 Accuracy Scores
| Model | Accuracy |
|-------|----------|
| Logistic Regression | 0.8946 |
| Linear SVM | 0.8945 |
| XGBoost | 0.8635 |
| Naive Bayes | 0.8617 |
